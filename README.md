# 🚀 فورم انضمام سيشن AI MASTERY

فورم تسجيل احترافي ومبتكر تم تصميمه خصيصاً للمهندس **أمير عادل عيد (Amir Adel Eid)** لسيشن **AI MASTERY**.

---

## 🌟 المميزات التقنية والبصرية

1. **إضاءات نيون وحواف متحركة (Animated Neon Borders)**:
   - كل خانة إدخال وكل بطاقة اختيار محاطة بحافة ضوئية متحركة وتدرج نيون (Cyan, Purple & Magenta) تدور بنعومة وتتسارع وتتوهج عند التمرير والكتابة.
2. **شعار وهوية م. أمير عادل عيد**:
   - تضمين الشعار الدائري الخاص بك مع حلقة نيون مشعة في رأس الصفحة.
3. **خلفية الذكاء الاصطناعي التفاعلية (Neural Network Canvas)**:
   - شبكة جزيئات عصبية متحركة تتفاعل مع حركة الماوس وتضفي طابع الذكاء الاصطناعي والتكنولوجيا الفائقة.
4. **الحقول المطلوبة بدقة**:
   - الاسم بالكامل.
   - رقم الواتساب (مع التحقق الذكي من صحة الرقم).
   - الجامعة / الكلية أو التخصص.
   - كروت تفاعلية مشعة لتحديد الهدف من الحضور:
     - *عشان تعرف تستخدم الذكاء الاصطناعي في مجالك*.
     - *عشان حابب مجال الـ AI وشغوف به*.
     - *الاثنان معاً (تطبيق عملي فوري + شغف بالمجال)*.
5. **روابط السوشيال ميديا**:
   - أزرار نيون مصممة خصيصاً لصفحة الفيسبوك وحساب الإنستجرام.
6. **نافذة تأكيد واحتفال فورية (Success Celebration Modal)**:
   - ظهور قصاصات احتفالية ملونة (Confetti) عند إتمام التسجيل بنجاح.
   - زر مباشر للتأكيد عبر رسالة واتساب مهيأة مسبقاً بنقرة واحدة.
7. **لوحة تحكم مصغرة للمنظم (Admin Dashboard)**:
   - زر تحكم عائم أسفل يمين الشاشة (`⚙️`) مخصص لك.
   - يعرض إجمالي عدد المسجلين وقائمتهم وتفاصيل كل مسجل.
   - زر لتحميل كشف كامل ببيانات المسجلين بصيغة **Excel (CSV)** متوافق مع اللغة العربية بضغطة زر!

## 💻 طريقة الاستخدام والتشغيل

1. **التشغيل المباشر**:
   - يكفي النقر المزدوج على ملف `index.html` ليفتح في أي متصفح (Google Chrome, Edge, Safari, Firefox).
2. **النشر أونلاين مجاناً**:
   - يمكنك رفع محتويات هذا المجلد إلى **GitHub Pages** أو **Vercel** أو **Netlify** خلال ثوانٍ معدودة وسيعمل كرابط رسمي مباشر يمكنك مشاركته مع المشتركين في منشوراتك وعلى السوشيال ميديا!
